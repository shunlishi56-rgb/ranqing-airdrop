# 苒晴空投 · 微信小程序

文件临时中转站：发送文字/图片/视频/文件 → 生成 6 位取件码 → 好友凭码取件 → 到期自动销毁。

技术栈：**uni-app (Vue3) + 微信云开发**（云函数 + 云数据库 + 云存储），无自建服务器。

## 功能一览

| 功能 | 说明 |
| --- | --- |
| 文字空投 | 最多 1000 字，实时字数统计 |
| 图片空投 | 最多 9 张，九宫格预览 |
| 视频空投 | 最长 60 秒 |
| 文件空投 | 从聊天记录选择，单文件 ≤ 50MB |
| 取件码 | 6 位（去除易混淆的 I/O/0/1），全库唯一 |
| 有效期 | 发送时自选 1 / 7 / 15 天，每天凌晨 3 点定时清理（数据库 + 云存储） |
| 内容安全 | 文字 msgSecCheck、图片 imgSecCheck（个人主体 UGC 过审必需） |
| 我的空投 | 查看取件码/浏览量/剩余时间，可复制、可手动删除 |
| 登录 | 微信静默登录（openid 自动建档），头像昵称用官方 chooseAvatar / nickname 组件 |

## 卡密系统说明

- **模型**：卡密 = 分时长使用资格（1天/7天/30天/永久），兑换后绑定使用者，时长可叠加顺延，永久卡不可再叠
- **发卡**：管理面板 → 卡密系统 → 选时长+数量 → 生成 → 复制卡号 → 通过公众号等渠道发放
- **兑换**：用户点「发送」→ 弹卡密兑换弹窗 → 输入卡号获得资格；「我的-使用资格」可看剩余天数与获取卡密入口
- **公众号引流**：管理面板 → 公众号引流 → 上传二维码图+引导文案，用户在获取卡密弹窗扫码关注
- **并发安全**：兑换用原子更新卡状态防重复兑换
- **门槛开关**：管理面板「卡密门槛」关闭 = 所有人免费使用（新用户自动永久资格）
- 卡号格式：`RQ1D-XXXX-XXXX`（1天）/ `RQ7D-…`（7天）/ `RQ30D-…`（30天）/ `RQFOREVER-…`（永久）

## 部署步骤（从零到预览）

### 1. 注册小程序（个人主体）

1. 到 [mp.weixin.qq.com](https://mp.weixin.qq.com) 注册**个人主体**小程序（免费），获得 AppID。
2. 类目建议：**工具 > 信息查询** 或 **工具 > 效率**（以审核时实际可选项为准）。

### 2. 开通云开发

1. 下载 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)（稳定版）。
2. 注意：云开发环境由"微信小程序"承担，本工程是 uni-app 项目，用 HBuilderX 编译后再在微信开发者工具里操作云开发。
   - 若你有 HBuilderX：用 HBuilderX 打开本工程 → 运行 → 运行到小程序模拟器 → 微信开发者工具。
   - 若没有 HBuilderX：在 [dcloud.io](https://www.dcloud.io/hbuilderx.html) 下载（标准版即可）。
3. 微信开发者工具中打开编译产物（HBuilderX 会自动拉起），点顶部 **「云开发」** 按钮 → 开通 → 创建环境（选**按量付费基础套餐**，约 19.9 元/月起）→ 记下**环境 ID**（形如 `xiaokongtou-1a2b3c`）。
4. 把环境 ID 填到 `utils/config.js` 的 `CLOUD_ENV`。
5. 把 AppID 填到 `manifest.json` → `mp-weixin.appid`（替换 `touristappid`）。

### 3. 上传云函数

在 HBuilderX 中，对 `cloudfunctions/` 下**每个**云函数目录：右键 → **上传并部署：云端安装依赖**（不要选"不上传 node_modules"）。

> `cleanup` 上传后，还需在微信开发者工具 → 云开发控制台 → 云函数 → cleanup → 触发器，确认 `dailyCleanup` 定时触发器已存在（config.json 已声明，通常自动创建；若没有则手动添加，cron：`0 0 3 * * * *`）。

### 4. 创建数据库集合与索引

云开发控制台 → 数据库 → 新建五个集合：

- `users`
- `parcels`
- `config`
- `receiveLogs`
- `cards`（卡密系统）

然后给 `parcels.code` 建**唯一索引**（数据库 → parcels → 索引管理 → 添加索引，字段 `code` 升序，勾选"唯一"）。

> 权限设置：三个集合都保持默认"仅创建者可读写"即可——所有读写都通过云函数（服务端）进行，不受该权限约束。

### 4.5 初始化配置（邀请码 + 管理员）

本项目采用**邀请码门槛**：新用户必须输入邀请码才能使用（老用户免验）。

1. 云函数面板 → 右键 `initSetup` → **云端测试**（无参数执行）→ 会在 config 集合写入初始文档
2. 微信开发者工具中打开小程序，进 **我的 → 关于区连点 5 次** → 进入管理面板
3. 首次进入会提示绑定：输入绑定密钥 `RQ-ADMIN-2026`（默认值，可部署前在 adminConfig 云函数代码中修改）→ 当前微信号绑定为管理员
4. 在管理面板中可随时修改邀请码（默认 `RQ8888`，上线前务必改）

管理员能力：查看全部空投（最新100条）、按取件码搜索、删除任意空投（连带云存储文件）、修改邀请码。

### 5. 运行预览

HBuilderX → 运行到微信开发者工具。测试流程：

1. 首页 → 发送 → 输入文字 → 选有效期 → 发送 → 得到取件码
2. 返回首页 → 接收 → 输入取件码 → 查看内容
3. 首页 → 我的 → 查看"我的空投"列表

## 与原版（iApp 小空头）的差异

| 项 | 原版 | 本版 |
| --- | --- | --- |
| 端 | iApp 安卓端 | 微信小程序（uni-app） |
| 后端 | PHP + MySQL（拼接 SQL，有注入漏洞） | 云函数 + 云数据库（参数化，天然免疫注入） |
| 密码 | 账号密码明文存储 | 微信 openid 静默登录，无密码 |
| 取件码 | `rand(0,999999)` 数字，可能冲突 | 去混淆字符集 6 位码 + 唯一索引 |
| 有效期 | 永不过期 | 1/7/15 天自选，定时销毁 |
| 内容类型 | 仅文字完整实现（图片/视频后端缺失） | 文字/图片/视频/文件全量 |
| 内容安全 | 无 | msgSecCheck + imgSecCheck |
